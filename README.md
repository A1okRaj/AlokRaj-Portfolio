## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/A1okRaj/AlokRaj-Portfolio.git
```

Navigate to project folder:

```bash
cd AlokRaj-Portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
